# زاد الإنجليزية (Zad English) — Rust + Tauri 2

تطبيق سطح مكتب خفيف وذكي لتعلم وممارسة مفردات اللغة الإنجليزية من **Oxford 3000 / 5000** حسب المستويات المعيارية الأوروبية (**A1, A2, B1, B2, C1, C2**)، مستوحى ومبني على معمارية تطبيق **[زاد المسلم](file:///teamspace/studios/this_studio/zad)**.

يعمل البرنامج بهدوء في الخلفية (System Tray)، ويُظهر نوافذ عائمة شفافة وأنيقة (Floating Desktop Widgets) بشكل دوري على شاشتك لتثبيت الكلمات في الذاكرة دون مقاطعة تركيزك أثناء العمل أو التصفح.

---

## ✨ أبرز المميزات

### 1. 🪟 الودجت العائم الذكي (Desktop Widget)
- تصميم عصري زجاجي (Glassmorphism) يدعم الوضع الداكن والفاتح (Dark / Light Theme).
- **الكلمة وتصنيفها**: الكلمة بالخط العريض، نوعها (Verb, Noun, Adj...)، ورمزها الصوتي بدقة (IPA).
- **نطق صوتي فوري**: استمع للكلمة بالنطق الأمريكي 🇺🇸 أو البريطاني 🇬🇧 بنقرة واحدة، مع خيار النطق التلقائي بمجرد الظهور.
- **المعنى والأمثلة**: ترجمة عربية دقيقة، تعريف مبسط بالإنجليزية، وجملة واقعية توضح الاستخدام في السياق مع ترجمتها.
- **المرادفات (Synonyms)**: بطاقات مرادفات تفاعلية يمكن النقر عليها للاستماع لنطقها.
- **التحكم بالخط والحجم**: تكبير وتصغير الخط بسهولة (A- / A+).

### 2. 🎯 وضع الاختبار السريع (Interactive Pop Quiz)
- نافذة اختبار ذكية تظهر دورياً (مثلاً كل 5 كلمات) لتنشيط الذاكرة.
- أسئلة اختيار من متعدد تفاعلية (4 خيارات) إما من الإنجليزية للعربية أو العكس.
- تصحيح فوري مع احتساب الـ Streak (مرات الإجابة الصحيحة المتتالية).

### 3. 🔄 نظام التكرار والمراجعة (Spaced Repetition)
- **حفظتها ✅**: تنقل الكلمة لقائمة الكلمات المتقنة وترفع نسبة إنجازك.
- **مراجعة 🔄**: تضع الكلمة في قائمة التركيز لتتكرر حتى تثبت تماماً.

### 4. ⚙️ شاشة الإعدادات والمعجم الشامل (Settings & Word Explorer)
- **فلترة المستويات**: اختر التركيز على مستوى محدد (A1, A2, B1, B2, C1, C2) أو كل المستويات معاً.
- **تحديد التوقيت**: فترة الظهور (5، 10، 15، 30، أو 60 دقيقة)، ومدة بقاء الودجت على الشاشة (15ث، 30ث، دقيقة، أو البقاء دائماً).
- **موضع الشاشة**: اختر زاويتك المفضلة (أسفل اليمين، أعلى اليمين، أسفل اليسار، أعلى اليسار).
- **معجم وبحث فوري**: تصفح وبحث في كافة الكلمات بالإنجليزية أو العربية، مع إمكانية عرض أي كلمة في الودجت فوراً.
- **التشغيل التلقائي (Autostart)**: يعمل التطبيق تلقائياً مع تشغيل نظام التشغيل.

## 🗂️ بنية المشروع

```text
zad-english/
├── data/
│   └── oxford_words.json          ← قاعدة مفردات أكسفورد المصنفة (A1-C2)
├── frontend/
│   ├── widget.html / widget.js    ← الودجت العائم السريع للكلمات
│   ├── quiz.html / quiz.js        ← نافذة الاختبار السريع
│   ├── settings.html / settings.js← شاشة الإعدادات والمعجم الشامل
│   ├── tauri-shim.js              ← جسر التواصل بين الـ Webview و Rust
│   └── styles/
│       ├── widget.css
│       ├── quiz.css
│       └── settings.css
└── src-tauri/
    ├── Cargo.toml
    ├── tauri.conf.json
    ├── build.rs
    ├── capabilities/default.json
    └── src/
        ├── main.rs / lib.rs       ← نقطة انطلاق التطبيق وإدارة الحالة
        ├── config.rs              ← حفظ إعدادات المستخدم وسجل التقدم
        ├── data_loader.rs         ← محرك فلترة وبحث الكلمات وتوليد الأسئلة
        ├── orchestrator.rs        ← محرك المؤقت الدوري في الخلفية
        ├── windows.rs             ← إدارة النوافذ الشفافة ومواقعها
        ├── tray.rs                ← قائمة شريط المهام (System Tray)
        └── ipc.rs                 ← أوامر Tauri IPC handlers
```

## 🚀 التشغيل والتطوير

### التشغيل في بيئة التطوير:
```bash
cd /teamspace/studios/this_studio/zad-english/src-tauri
cargo run
```

### فحص الكود:
```bash
cargo check
```

### بناء ملف التثبيت النهائي (Release Binary / Windows Installer):
```bash
cargo build --release
```
أو عبر Tauri CLI:
```bash
npx @tauri-apps/cli build
```
