**زاد الإنجليزية (Zad English)** هو تطبيق سطح مكتب خفيف، أنيق وذكي لتعلم وممارسة مفردات اللغة الإنجليزية من قائمة **Oxford 3000 / 5000** بدقة أكاديمية عالية ومصنفة بحسب الإطار الأوروبي المشترك (**A1, A2, B1, B2, C1, C2**)، مستوحى ومبني على معمارية تطبيق **[زاد المسلم](https://github.com/ARK024/zad)**.

يعمل البرنامج بهدوء في الخلفية (System Tray)، ويُظهر نوافذ عائمة شفافة وأنيقة (Floating Desktop Widgets) بشكل دوري لتثبيت الكلمات في الذاكرة دون مقاطعة تركيزك أثناء العمل أو التصفح.

## ✨ أبرز المميزات

### 1. 🪟 الودجت العائم الذكي (Desktop Widget)
- تصميم عصري زجاجي (Glassmorphism) يدعم الوضع الداكن والفاتح (Dark / Light Theme).
- **الكلمة وتصنيفها**: الكلمة بالخط العريض، نوعها (Verb, Noun, Adj...)، ورمزها الصوتي بدقة (IPA).
- **نطق صوتي ثنائي (Dual IPA & Audio)**: استمع للكلمة بالنطق الأمريكي 🇺🇸 أو البريطاني 🇬🇧 بنقرة واحدة، مع خيار النطق التلقائي بمجرد الظهور.
- **صوتيات بشرية حقيقية بدون إنترنت (100% Offline Human Audio)**: دعم كامل لتشغيل 9,912 ملف صوتي بشري أصلي من قواميس أكسفورد أوفلاين.
- **المعنى والأمثلة**: ترجمة عربية دقيقة تناسب نوع الكلمة وسياقها النحوي، تعريف مبسط بالإنجليزية، وجملة واقعية توضح الاستخدام مع ترجمتها الكاملة.
- **التحكم بالخط والحجم**: تكبير وتصغير الخط بسهولة (A- / A+).

### 2. 🎯 وضع الاختبار السريع (Interactive Pop Quiz)
- نافذة اختبار ذكية تظهر دورياً (مثلاً كل 5 كلمات) لتنشيط الذاكرة.
- أسئلة اختيار من متعدد تفاعلية (4 خيارات) إما من الإنجليزية للعربية أو العكس.
- تصحيح فوري مع احتساب الـ Streak (مرات الإجابة الصحيحة المتتالية).

### 3. 🔄 نظام التكرار والمراجعة (Spaced Repetition)
- **حفظتها ✅**: تنقل الكلمة لقائمة الكلمات المتقنة وترفع نسبة إنجازك.
- **مراجعة 🔄**: تضع الكلمة في قائمة التركيز لتتكرر حتى تثبت تماماً.

### 4. ⚙️ شاشة الإعدادات والمعجم الشامل (Settings & Word Explorer)
- **فلترة المستويات**: اختر التركيز على مستوى محدد (A1, A2, B1, B2, C1, C2) أو كل المستويات معاً (6,207 كلمة).
- **تحديد التوقيت**: فترة الظهور (5، 10، 15، 30، أو 60 دقيقة)، ومدة بقاء الودجت على الشاشة (15ث، 30ث، دقيقة، أو البقاء دائماً).
- **موضع الشاشة**: اختر زاويتك المفضلة (أسفل اليمين، أعلى اليمين، أسفل اليسار، أعلى اليسار).
- **معجم وبحث فوري**: تصفح وبحث في كافة الكلمات بالإنجليزية أو العربية، مع إمكانية عرض أي كلمة في الودجت فوراً.
- **إدارة الصوتيات أوفلاين**: عرض حالة الحزم الصوتية المثبتة محلياً.
- **التشغيل التلقائي (Autostart)**: يعمل التطبيق تلقائياً مع بدء تشغيل النظام.

## 🎧 تحميل الحزم الصوتية أوفلاين (Offline Audio Setup)

إذا رغبت في تثبيت كافة التسجيلات الصوتية البشرية (9,912 ملف MP3) لتعمل بدون نت نهائياً، يوفر المشروع سكريبت تلقائي:

```bash
python3 scripts/download_audio.py
```
يقوم السكريبت تلقائياً بتحميل وفك ضغط حزمتي النطق الأمريكي والبريطاني في مجلد `audio/`.

## 🛠️ البناء والتطوير محلياً (Build from Source)

### المتطلبات:
- [Rust](https://www.rust-lang.org/) (إصدار 1.75 أو أحدث)
- [Node.js](https://nodejs.org/) (لتشغيل `@tauri-apps/cli`)
- حزم النظام الأساسية (على لينكس): `libwebkit2gtk-4.1-dev`, `libgtk-3-dev`, `libayatana-appindicator3-dev`

### خطوات البناء:
```bash
# 1. تثبيت أدوات Tauri
npm install -g @tauri-apps/cli

# 2. تشغيل التطبيق في وضع التطوير
tauri dev

# 3. بناء النسخة الإنتاجية (Release)
tauri build
```
